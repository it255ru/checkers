# Браузерная игра в русские шашки против шашечного движка. 

Один HTML-файл, без зависимостей и сборки: открывается двойным кликом, работает офлайн, публикуется на любом статическом хостинге.

## Быстрый старт

**Локально:** скачайте `checkers.html` и откройте в браузере. Играйте.

**Со своими картинками:** рядом с файлом создайте структуру

```
checkers.html
media/
  model1/
    logo.jpg          ← иконка в панели выбора
    00.jpg 01.jpg …   ← картинки-награды
  model2/
    …
```

Каталоги ищутся автоматически по именам `model1`–`model99` (другие имена можно перечислить в `SETTINGS.fallbackDirs` в начале скрипта). Если браузер блокирует загрузку с диска (Chrome и `file://`), запустите локальный сервер: `python -m http.server` и откройте `http://localhost:8000/checkers.html`.


## Управление

| Элемент | Действие |
|---|---|
| Клик по своей шашке | выбор (повторный клик — отмена) |
| Зелёные клетки | доступные ходы; при серии боя ходы только по цепочке |
| Пульсирующая шашка | обязана бить |
| ← К выбору / ⟳ Заново | смена каталога / новая партия |
| 💡 | подсказка: лучший ход за белых (фиксируется в логе) |
| 📋 Лог | журнал ходов для разбора и копирования |

## Структура проекта

```
checkers.html              # игра целиком: правила, движок, интерфейс

.github/workflows/ci.yml   # тесты + публикация на Pages
media/                     # картинки (не входят в репозиторий-шаблон)
```
